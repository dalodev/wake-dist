Status ​

sh
wake-server status

It prints, in this order:

  • the installed version and the address Wake serves;
  • the people the free plan counts, such as People: 2 of 3 (free plan), or People: unknown when the server cannot answer (see Free plan accounts);
  • how many backups backups/ holds, the space they use and where they are, such as Backups: 2 using 1.2 GiB in /home/you/wake-server/backups, or Backups: none;
  • each service's health: postgres, minio, server, web and caddy;
  • whether a newer stable release exists, with the command that upgrades to it.

When Docker is not running, it prints the first three lines, then ! Docker is not running: start it with wake-server start, and exits 1. When every service is stopped it says to run wake-server start. When GitHub cannot be reached it says the newest release is unknown, and still exits 0.

wake-server status asks GitHub for the newest release itself, even when the server's own update check is off.

From a repository ​

In a repository connected to this installation, wake doctor checks the connection, your login, the server's version and every connected agent, and names the fix for each failed check. When the server cannot be reached and it is the one the installer recorded on this machine, the fix is wake-server start. See Troubleshooting.
