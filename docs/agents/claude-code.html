Claude Code ​

Connect a repository to Claude Code from its directory:

sh
wake connect claude-code

wake setup --agent claude-code runs it for you. Commit the files it writes.

What you get ​

Five commands you type in Claude Code:

CommandWhat it does
/wake:nextProposes the next free task and claims it once you confirm
/wake:statusShows the tasks this session holds, the free ones and what is left in the open milestone; changes nothing
/wake:plan <idea>Plans the idea with the repository's planning method, without writing code
/wake:doneRuns the repository's checks, attaches evidence and completes the task this session holds
/wake:releaseReleases the open milestone with the repository's own process, asking before every push, tag or publish

The wake and wake-planning skills tell Claude Code how to claim, plan and finish work. Hooks run wake hook when a session starts, after each tool call and when it ends, with the CLI's sign-in, so the CLI must be installed and signed in on this machine.

Files it writes ​

  • .mcp.json: Wake's MCP server, wake, at <your Wake URL>/mcp.
  • .claude/settings.json: Wake's plugin marketplace, with auto-update on, and the wake plugin, which brings the hooks, the skills and the commands.
  • The Wake block in CLAUDE.md, or in AGENTS.md when CLAUDE.md imports it with a line @AGENTS.md or when the repository has only AGENTS.md.

No file holds a token. Claude Code fetches the marketplace and the plugin from the public repository https://github.com/dalodev/wake-dist.git: no GitHub account is needed.

Sign in ​

  1. Open Claude Code in the repository and trust the folder when it asks. Claude Code reads the project's MCP server, marketplace and plugin only after you trust it.
  2. Accept the wake MCP server and install the wake plugin when Claude Code offers them. If you dismissed the plugin, run /plugin, find wake in the wake marketplace and install it, or run claude plugin install wake@wake --scope project in the repository; without it, no Wake hook or command runs.
  3. Run /mcp, choose wake and allow Claude Code in the browser.

Updates ​

Claude Code updates the wake plugin by itself, in the background after start-up, whenever a stable Wake release ships. There is nothing to commit. A repository connected by an older Wake may need one more step: see Older installations.
