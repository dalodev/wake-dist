Questions ​

Short answers to what people ask before they install Wake.

Which systems does Wake run on? ​

macOS, Linux, and Windows through WSL 2, on amd64 or arm64, with Docker. On Windows, Wake installs and runs inside a WSL 2 Linux distribution; see Windows with WSL 2.

Is there a hosted version? ​

No. Wake runs only on a machine you own, and its license does not allow offering it to others as a hosted service; see Install Wake and License.

Who counts toward the 3 people? ​

Every person who uses Wake for you and your company, however many installations you run, and whatever their role: owners, members and viewers. Someone who uses Wake through a bot or a shared tool counts too. On each installation, every active account counts; pending invitations, agents, personal access tokens and OAuth clients never count, and a disabled account frees its place; see Free plan accounts and License.

Can a teammate use my local installation? ​

No. A local installation answers only on your machine, at localhost. For teammates on other machines, install Wake on a server they can reach with --domain, which serves it over HTTPS; see Install on a domain.

What happens past 3 people? ​

Each installation refuses its fourth account, by password, invitation or sign-in provider, and says how to free a place: wake-server accounts disable <email>; see Free plan accounts.
