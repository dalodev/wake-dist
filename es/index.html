Una tarea, del plan a la prueba.

Desplázate para seguirla. Nadie actualiza un ticket a mano.

  1. 1 / 5

    El plan, en git

    Tu agente escribe el plan junto a tu código, con OpenSpec, Spec Kit u ODD. Lo revisas como cualquier otro cambio.

  2. 2 / 5

    Reservar la tarea

    El agente la reserva antes de tocar el código. Desde ese momento, nadie más puede reservarla.

  3. 3 / 5

    Trabajo a la vista

    Las ediciones y los tests llegan al roadmap en el momento. Ves quién, qué y durante cuánto tiempo.

  4. 4 / 5

    Demostrar que funciona

    El agente adjunta resultados de tests, capturas y logs. Se guardan en tu propio servidor.

  5. 5 / 5

    Hecha, en el roadmap

    La tarea se vuelve azul, la fase avanza y la estimación se actualiza.

Instala Wake gratis

Instala Wake en tres pasos.

Una vez por ordenador, una vez por repositorio y una vez por agente.

Necesitas
Docker y Node.js 24 o posterior
Funciona en
macOS, Linux o Windows (WSL 2)

¿Lo alojas para un equipo en tu propio dominio? Guía del servidor →

  1. 1

    Instala Wake

    terminal
    curl -fsSL https://github.com/dalodev/wake-dist/releases/latest/download/install.sh | sh

    Arranca el servidor en tu ordenador y abre el navegador para que crees tu cuenta.

  2. 2

    Conecta un repositorio

    en el repositorio git de tu proyecto
    wake setup

    El navegador toma el relevo: ponle nombre al proyecto y elige tu agente. Haz commit de lo que Wake añade; no contiene secretos.

  3. 3

    Conecta tu agente, una vez

    Tu agente de programación
    1. 1

      Abre Claude Code en el repositorio y acepta el plugin de Wake. O instálalo tú:

      claude plugin install wake@wake --scope project
    2. 2

      Ejecuta esto dentro de Claude Code, elige wake y aprueba:

      /mcp

    Después, abre una sesión: tu agente empieza sabiendo el proyecto y sus siguientes tareas.

Preguntas antes de instalar.

¿Dónde están mi código y mis datos?

En el equipo donde instalas Wake. Tu código se queda en tu repositorio. Las tareas, la actividad y las pruebas se guardan en la base de datos y el almacenamiento de Wake, en ese mismo equipo.

Instalar Wake
¿Qué agentes funcionan con Wake?

Claude Code, Codex, OpenCode y Pi. Puedes conectar varios al mismo repositorio.

Agentes y planes
¿Qué pasa a partir de 3 personas?

El plan gratuito permite 3 personas en total, tengas las instalaciones que tengas. Cada instalación rechaza una cuarta cuenta hasta que quien administra Wake desactiva una con wake-server accounts disable. Los agentes nunca cuentan.

Cuentas del plan gratuito
¿Qué permite la licencia?

Puedes usar Wake para hasta 3 personas, copiarlo y modificarlo. No puedes ofrecerlo a terceros como servicio alojado ni saltarte los límites del plan gratuito. El CLI y las integraciones con los agentes son MIT.

Licencia
¿Wake envía algo a casa?

No hay telemetría. Tu servidor pregunta a GitHub por la versión más reciente, y puedes desactivarlo.

Cómo te enteras de una versión nueva
¿Cómo lo desinstalo?

wake disconnect quita Wake de un repositorio. Para eliminar el servidor, borra sus contenedores y su directorio.

Desinstalar Wake

Pon a todos tus agentes en un mismo roadmap.

Qué muestra la demo

  2. Tres agentes trabajan en el mismo repositorio, cada uno con su nombre y una línea de trabajo.

    Tres agentes trabajando. ¿Quién hace qué?

    Un comando los pone a todos en el mismo roadmap.
