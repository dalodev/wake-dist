Install Wake free

Install in three steps.

The first runs once per machine, the second once per repository, the third once per agent. Everything after that updates itself.

You need
Docker, and Node.js 24 or newer for the wake command
Works on
macOS, Linux or Windows (WSL 2)
Agents
Claude Code, Codex, OpenCode or Pi

Hosting it for a team on your own domain? End the first command with sh -s -- --domain wake.example.com instead of sh, and Wake serves HTTPS with its own certificate. Both the domain and s3. on it must point at the server.

  1. 1

    Install Wake on your machine

    terminal
    curl -fsSL https://github.com/dalodev/wake-dist/releases/latest/download/install.sh | sh

    It starts the server with its database and file storage in ~/wake-server, installs the wake command, turns on daily upgrades with a backup first, and opens your browser to create your account.

  2. 2

    Connect a repository

    in your project's git repository
    wake setup

    Your browser takes over: confirm the code, name the project and pick your agent. Wake reads your plan and prepares the agent. Commit the files it adds; none holds a secret.

  3. 3

    Sign your agent in, once

    Your coding agent
    1. 1

      Open Claude Code in the repository, trust the folder and accept the Wake plugin when it is offered. Or install it yourself:

      claude plugin install wake@wake --scope project
    2. 2

      Run this inside Claude Code, choose wake and approve in the browser:

      /mcp

    Then start a session: your agent starts out knowing the project and its next tasks.

Questions before you install.

Where do my code and data live?

On the machine where you install Wake. Your code stays in your repository. Wake keeps the tasks, the activity and the evidence in its own database and file storage, in Docker on that machine.

Install Wake
Which agents work with Wake?

Claude Code, Codex, OpenCode and Pi. wake connect gives each one Wake's MCP server, its hooks and its skills, and you can connect several in the same repository.

Agents and plans
What happens past 3 people?

The free plan allows 3 people in all, however many installations you run. Each installation refuses a fourth account until whoever runs Wake disables one with wake-server accounts disable. Agents never count.

Free plan accounts
What does the license allow?

You can run Wake for up to 3 people, copy it and change it. You can't offer it to others as a hosted service or get around the free plan's limits. The wake CLI and the agent integrations are MIT.

License
Does Wake send anything home?

No telemetry. Your server asks GitHub for the newest release when it starts and every 12 hours, sending only its version, and upgrades download signed releases from GitHub. WAKE_UPDATE_CHECK=off stops the check.

How you hear of a new release
Which systems does it run on?

macOS, Linux or Windows with WSL 2, on amd64 or arm64, with Docker and its Compose v2 plugin. On Windows, Wake installs and runs inside a WSL 2 Linux distribution, with Docker Desktop's WSL integration turned on for it. The wake command needs Node.js 24 or newer.

Windows with WSL 2
What does Wake write to my repository?

.wake/config.json, which names the server and the project, your agent's configuration, hooks and skills, a Wake block in CLAUDE.md or AGENTS.md, and a short wake: id on each OpenSpec task. None of these files holds a token.

Connect a repository
How do upgrades and backups work?

The installer turns on a daily upgrade that backs up first and rolls back, data included, when the new version isn't healthy. wake-server backup writes a backup whenever you want, and wake-server restore puts one back.

Upgrade
How do I remove it?

Turn off the daily upgrade, back up if you want to keep the data, then delete Wake's containers, volumes and directory. wake disconnect takes Wake out of each repository.
