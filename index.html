Install Wake free

Install in three steps.

Once per machine, once per repository, once per agent.

You need
Docker and Node.js 24+
Works on
macOS, Linux, Windows (WSL 2)

Hosting it for a team on your own domain? Server guide →

  1. 1

    Install Wake

    terminal
    curl -fsSL https://github.com/dalodev/wake-dist/releases/latest/download/install.sh | sh

    Starts the server on your machine and opens your browser to create your account.

  2. 2

    Connect a repository

    in your project's git repository
    wake setup

    Your browser takes over: name the project and pick your agent. Commit what Wake adds; it holds no secrets.

  3. 3

    Sign your agent in, once

    Your coding agent
    1. 1

      Open Claude Code in the repository and accept the Wake plugin. Or install it yourself:

      claude plugin install wake@wake --scope project
    2. 2

      Run this inside Claude Code, choose wake and approve:

      /mcp

    Then start a session: your agent starts out knowing the project and its next tasks.

Questions before you install.

Where do my code and data live?

On the machine where you install Wake. Your code stays in your repository. Tasks, activity and evidence stay in Wake’s database and storage, on that same machine.

Install Wake
Which agents work with Wake?

Claude Code, Codex, OpenCode and Pi. You can connect several to the same repository.

Agents and plans
What happens past 3 people?

The free plan allows 3 people in all, however many installations you run. Each installation refuses a fourth account until whoever runs Wake disables one with wake-server accounts disable. Agents never count.

Free plan accounts
What does the license allow?

You can run Wake for up to 3 people, copy it and change it. You can’t offer it to others as a hosted service or get around the free plan’s limits. The CLI and the agent integrations are MIT.

License
Does Wake send anything home?

No telemetry. Your server asks GitHub for the newest release, and you can turn that off.

How you hear of a new release
How do I remove it?

wake disconnect takes Wake out of a repository. To remove the server, delete its containers and its directory.
